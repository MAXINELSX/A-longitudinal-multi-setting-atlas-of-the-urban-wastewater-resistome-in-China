# Tier I analysis code snapshot

Snapshot: `tieri-analysis-20260925`

This snapshot corresponds to Supplementary Methods S3-5 and S3-6 and the numerical results in Supplementary Data S5-2–S5-6 accompanying the manuscript dated 25 September 2026. It does not replace the original priority list in S5-1.

The analysis routines are taken from the threshold-sensitivity and fixed-panel consistency workflows used to generate those tables. Filesystem paths are command-line arguments. The preparation and export steps use ordinary CSV files and do not require the software used for page layout. Counts used to size arrays or validate input structure are derived from the inputs. The numerical rules, period boundaries, random-number generator and default seed are unchanged.

`TIERI_SHA256SUMS.txt` identifies the files in this snapshot. Input-file hashes and software versions are recorded when the workflows run. This package contains code and documentation only; it does not include study records.

After uploading, create a repository tag or release named `tieri-analysis-20260925` at that commit and record the actual commit identifier with the manuscript. This is a proposed release name, not a claim that a remote release or DOI already exists. Subsequent analysis changes should receive a new version rather than replacing this snapshot.
