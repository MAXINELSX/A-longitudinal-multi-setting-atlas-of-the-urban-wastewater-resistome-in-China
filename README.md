# Urban wastewater resistome analyses

R scripts for the main, supplementary and extended-data figures, and Python scripts for the Tier I sensitivity and internal-consistency analyses. Inputs are read from external files; no study records are embedded in the scripts.

| Script | Coverage |
| --- | --- |

| `fig2_a-h.R` | Fig. 2a–h |
| `Fig3_abcde.R` | Fig. 3a–e |
| `Fig4_cde.R` | Fig. 4c–e |
| `Fig5_b_to_g.R` | Fig. 5b–g |
| `Fig6_a_to_h.R` | Fig. 6a–h |

| `TierI_export_tables.py` | Table-numbered CSV exports of saved S5-2–S5-6 results |

Maps, study-design diagrams, externally rendered trees and final page assembly are not generated by these scripts.

## Running the scripts

Use a separate R session for each R script. `source()` loads functions without starting a figure workflow. Supply the input paths or data frames required by the entry point. Input validation reports missing columns, duplicated keys and incompatible data. Model diagnostics and comparison tables should be checked before using newly generated significance letters.

Dependencies include `readr`, `readxl`, `openxlsx`, `data.table`, `tidyverse`, `dplyr`, `tidyr`, `tibble`, `purrr`, `stringr`, `forcats`, `ggplot2`, `scales`, `cowplot`, `patchwork`, `ggrepel`, `ggnewscale`, `ggalluvial`, `VennDiagram`, `ComplexHeatmap`, `circlize`, `RColorBrewer`, `networkD3`, `htmlwidgets`, `jsonlite`, `vegan`, `permute`, `lme4`, `lmerTest`, `multcompView`, `rstatix`, `FSA`, `performance`, `randomForest`, `rfPermute`, `VIM` and `nnls`. Some export options additionally use `svglite`, `ragg` or `rsvg`. `ComplexHeatmap` is distributed through Bioconductor. Install the packages needed for the selected panels before running them. Each analysis writes its current R session information where supported.

Detailed input formats and calls for Fig. 3, Fig. 4, Fig. 6, Supplementary Figs. S2–S14 and Extended Data Figs. 1–3 are in [INPUTS.md](INPUTS.md).

### Fig. 1

```sh
Rscript fig1_btoe.R --metadata data/fig1/sample_metadata.csv --subtype-dir data/subtypes --output results/Fig1_b-e.pdf
```

Metadata columns: `Sample`, `Clean_Reads_GBp`, `City`, `Sample_Type`, `Sample_Date`. Dates may use `YYYYMMDD` or `YYYY-MM-DD`. The subtype directory contains `hospital_subtypes.xlsx`, `wwtp_subtypes.xlsx`, `community_subtypes.xlsx` and `wet_market_subtypes.xlsx`. Each sheet has a subtype identifier column and one abundance column per sample.

### Fig. 2

```r
Sys.setenv(FIG2_DATA_ROOT = "data/fig2",
           FIG2_METADATA_FILE = "data/fig2/sample_metadata.xlsx",
           ARG_EXTERNAL_DATA_ROOT = "data",
           ARG_RESULTS_DIR = "results/fig2")
source("fig2_a-h.R")
run_fig2()
```

Metadata columns: `Sample`, `City`, `Sample_Date` (`YYYYMMDD`), `Sample_Rename`. A terminal `_YYYYMMDD` is removed from `Sample_Rename` to obtain the physical-site identifier. The four abundance workbooks are named `subtype_by_site_医院.xlsx`, `subtype_by_site_污水处理厂.xlsx`, `subtype_by_site_社区.xlsx` and `subtype_by_site_农集贸市场.xlsx`; set `FIG2_SUBTYPE_SUFFIX` if their common filename suffix differs. The first column contains subtype IDs; subsequent columns contain sample abundances. Blank abundance cells and numeric zeros denote nondetection. Metadata missingness is not imputed.

Panel d additionally reads `data/c_merge/final_global.xlsx`. Set `FIG2_PANELS` before sourcing to select panels, for example `"a,b,c,e,f,g,h"` without the external benchmark. Panels b and c run together. Panel b uses a negative-binomial mixed model; panel c uses an original-scale LMM. The six setting contrasts are BH-adjusted within each outcome. Panel f clusters ARG types, not subtypes.

### Fig. 5

```sh
Rscript Fig5_b_to_g.R data/tier1 data/sample_metadata.xlsx data/prioritization results/fig5 bcdefg
```

The abundance workbooks follow the Fig. 2 layout and contain the selected Tier I subtype roster. Set `FIG5_SUBTYPE_SUFFIX` if needed. Metadata may instead be a CSV containing `Sample`, `Setting`, `City`, `PhysicalSite`, `Sample_Date` and `SamplingMonth`. The prioritization directory contains `subtype_risk_4level_core_only_final.csv`, `subtype_level_I_core_only.csv`, `core_subtype_list.csv` and `panel_subtype_mobility_summary.csv`.

Panel d uses Bray–Curtis dissimilarities from original abundances and runs both PERMANOVA and PERMDISP. Panel e uses an original-scale LMM. Panels f and g first sum constituent subtypes within samples, then calculate arithmetic means. Panel g maps mean abundance to bubble size on a logarithmic scale and relative deviation from the row mean to colour.

## Tier I sensitivity and internal consistency

The Python workflows correspond to Supplementary Methods S3-5 and S3-6. Threshold sensitivity holds core membership and assessment eligibility fixed while varying the Tier I cutoffs. Internal-consistency analyses retain the original Tier I panel without adding candidates. Neither workflow reconstructs host or mobility evidence from raw annotation records. S5-1 remains the original priority list.

Use Python 3.12 and install the dependencies:

```sh
python -m pip install -r requirements-tieri.txt
```

Run from the repository root, supplying local input paths:

```sh
python TierI_threshold_sensitivity.py --core data/prioritization/core_subtype_list.csv --assessed data/prioritization/subtype_risk_4level_core_only_final.csv --original-tier1 data/prioritization/subtype_level_I_core_only.csv --hosts who_species.txt --output results/tieri_thresholds
python TierI_prepare_inputs.py --metadata data/canonical_sample_metadata.csv --abundance-long data/tier1/filtered_target_subtypes_long_table.csv --original-tier1 data/prioritization/subtype_level_I_core_only.csv --membership results/tieri_thresholds/TierI_subtype_membership.csv --output results/tieri_inputs
python TierI_internal_consistency.py --input-dir results/tieri_inputs --output results/tieri_consistency --repetitions 1000 --seed 20260925
python TierI_export_tables.py --threshold-dir results/tieri_thresholds --input-dir results/tieri_inputs --analysis-dir results/tieri_consistency --output results/tieri_tables
```

If the prepared inputs are supplied directly, skip the preparation step. If all analysis outputs have already been generated, run only `TierI_export_tables.py`; this exports saved results without recalculating threshold assignments or resampling. The optional preparation argument `--workbooks` accepts the four original setting-specific XLSX matrices for a cell-by-cell check against the long table.

| Table | Analysis output |
|---|---|
| S5-2 | Nine mobility-by-host-breadth combinations; `S5-2_threshold_summary.csv` |
| S5-3 | Subtype membership under each combination; `S5-3_subtype_membership.csv` |
| S5-4 | Fixed-panel city/time recurrence and per-subtype subsampling retention; `S5-4_subtype_consistency.csv` |
| S5-5 | City-, month- and period-specific setting profiles; `S5-5_stratum_profiles.csv` |
| S5-6 | `S5-6_temporal_schemes.csv`, `S5-6_balanced_subsampling.csv`, `S5-6_period_concordance.csv` and `S5-6_matched_sample_coverage.csv` |

S5-6 contains four result blocks, exported separately as CSV files. These are the numerical tables, not a recreation of the workbook page layout. Required fields, denominators, weighting, missing-value rules and ordering requirements are documented under **Tier I analyses** in [INPUTS.md](INPUTS.md).

Threshold analysis uses mobility cutoffs 0.60/0.70/0.80 and host-breadth cutoffs 2/3/4. Fixed-panel recurrence uses prevalence ≥70% and mean abundance ≥10⁻⁵ copies per cell. The two periods are November 2024–May 2025 and June–December 2025. Balanced draws are made without replacement within each common site and period. Resampling percentiles describe these draws; they are not confidence intervals or independent validation.

## Data requests

The following analysis inputs are not included in this code package and are available from the corresponding author on request:

- Fig. 3b,c ORF-level counts and sample-level numerators and denominators;
- MAG quality records and ARG counts;
- complete wastewater–clinical genome cluster membership and screening edges;
- hospital-quarter analysis inputs.

The Tier I scripts also require external prioritization inputs, the fixed-panel abundance table and canonical sample metadata. These inputs are not bundled with the code and may be requested through the same corresponding-author and peer-review routes. Public aggregate results are reported in Supplementary Data S5-1–S5-6. The public `who_species.txt` file defines the predefined host set.

Requests should be addressed to the corresponding author listed in the manuscript. During peer review, these inputs will be provided to editors and reviewers on request through the editorial office.
